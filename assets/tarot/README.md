# 타로 카드 그림

`cards/` 폴더에 78장이 카드 id 이름으로 들어 있다 (`major-00.jpg` ~ `major-21.jpg`,
`wands-01.jpg` ~ `wands-14.jpg`, `cups-..`, `swords-..`, `pents-..`; 01=에이스, 11=페이지, 12=나이트, 13=퀸, 14=킹).

- 지금 그림: 1909년 라이더-웨이트-스미스 덱 원판 스캔 (Pamela Colman Smith 그림, 퍼블릭 도메인).
  출처: Wikimedia Commons의 `RWS_Tarot_*.jpg`, `Wands01.jpg` 등. 폭 400px로 줄였다.
- 직접 그린 그림으로 바꿀 때는 같은 파일 이름으로 덮어쓰면 된다. 비율은 약 0.578(가로/세로).
- 카드 이름과 해석은 `cards.json`.
